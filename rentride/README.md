# RentRide — improved landing

Azerbaijani car-rental landing redesign focused on:

- Brand-first hero (RentRide as the primary signal)
- Full-bleed imagery without clutter overlays
- Search as a dedicated interaction section (not on the hero)
- Distinctive type: Unbounded + Plus Jakarta Sans
- Caspian teal accent on cool slate atmosphere
- Subtle entrance / scroll motion

## Run locally

```bash
cd rentride
python3 -m http.server 4173
```

Open http://localhost:4173
